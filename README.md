# Video2GIF open-source materials

Versioned releases contain the corresponding FFmpeg and zimg sources, local changes, notices, build instructions, and App object materials for relinking Video2GIF with a compatible modified library.

Choose the release matching the version and build number shown in Video2GIF. Check SHA256SUMS.txt after downloading and read the included README and library notices. These packages do not include the original App executable, developer signing credentials, Apple SDK, or user videos.

This repository distributes license materials. It is not the App source repository or an App installer. Each included component retains its own license. Instructions and limitations for personal relinking and signing are in the package.
